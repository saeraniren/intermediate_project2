# 🚀 프로젝트 소개

---

- 프로젝트명 : 공유 오피스 서비스 분석 및 개선방향 제언
- 진행 기간 : 2025년 4월 18일 ~ 2025년 4월 29일
- 주요 업무 : 다양한 지도학습 분류모델을 통한 인사이트 도출 및 데이터 크롤링 기술 활용
- 활용 기술
    - XGBoost와 CatBoost를 이용한 분류분석을 실행 후 각 모델들의 성능을 비교한 뒤, 성능이 좋은 모델을 토대로 Feature Importance를 통해 분석 인사이트 도출
    - javascript 동적 렌더링으로 작동되는 페이지를 Selenium을 이용한 동기 데이터 크롤링을 통한 데이터 수집

# 👤 프로젝트에서 진행한 역할

---

## 1. 지도학습 알고리즘을 통한 데이터 분석

프로젝트 데이터셋 내 다양한 독립변수들의 특성을 심층적으로 분석하고, 지도학습 기반 분류 알고리즘(CatBoost, XGBoost)을 적용하여 종속변수와의 관계를 체계적으로 모델링하였다. 모델 성능 평가(Accuracy, Precision, Recall 등)를 통해 최적 알고리즘을 선정하고, 이를 기반으로 주요 인사이트를 도출하였다.

## 2. 동적 렌더링 페이지를 selenium으로 데이터 크롤링

프로젝트에 필요한 외부 보조 데이터를 확보하기 위해, Selenium을 활용하여 동적 렌더링 구조를 가진 웹페이지에서 필요한 정보를 자동화 크롤링하였다. 수집 대상은 해당 각 건물들의 건물면적과 연면적이었으며, 크롤링과정에서 사용자 인터렉션을 자동화했으며, 수집한 면적 데이터를 정제 및 통합하여 프로젝트의 ROI 도출 및 무료 체험의 전환율 평가에 활용하였다.

# 💡프로젝트 내 회고

---

프로젝트를 진행하면서 데이터셋 내 부족한 정보를 보완하기 위해 다양한 공공데이터 및 웹 크롤링을 통해 외부 데이터를 수집하였다. 그러나 공유오피스 실제 운영 공간(실사용 면적) 정보를 확보하는 데에는 한계가 있었다. 건물면적이 50평이라고 하더라도, 공용부지(예: 복도, 로비 등)를 제외한 실제 사용면적을 정확히 파악할 수 없어, "건물면적 전체를 공유오피스가 사용하는 것"이라는 가정 하에 분석을 진행하게 되었다. 이 과정에서 데이터의 한계가 분석 결과에 미치는 영향을 깊이 체감할 수 있었고, 데이터 기반 가정 설정의 중요성을 다시 한번 깨달았다.

지도학습 과정에서는 다양한 Feature Engineering을 시도하지 못한 아쉬움이 있었다. 초기에 '내 역량의 한계'를 느꼈지만, 예상보다 높은 모델 성능(Accuracy, Precision, Recall)을 확인하면서, 데이터 특성과 기본적인 변수 선정만으로도 일정 수준 이상의 결과를 얻을 수 있다는 점을 배웠다.

이번 프로젝트를 통해 "완벽한 데이터는 없다"는 점과, 데이터의 한계를 인정하고 그 안에서 최선의 분석을 설계하는 능력이 중요함을 실감하였다. 또한 제한된 정보 속에서도 의미 있는 인사이트를 도출하는 경험을 통해 데이터 분석가로서 한 단계 성장할 수 있었던 값진 기회였다.
